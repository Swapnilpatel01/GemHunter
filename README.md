# GemHunter

The GemHunter app — a hidden-gem stock researcher and Robinhood copilot — as a PWA hosted on GitHub Pages.

This repo holds only the app. Your research, portfolio and the AI engine live in your private **GemHunter-data** repo; the app reads and writes there through the GitHub API with a token stored on your phone, and research runs on GitHub Actions using your Claude plan.

Open https://swapnilpatel01.github.io/GemHunter/ on your iPhone and choose Share → Add to Home Screen.
